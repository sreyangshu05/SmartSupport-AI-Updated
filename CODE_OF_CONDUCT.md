# Code of Conduct

## Expected Behavior

Contributors are expected to:

- Communicate respectfully and constructively.
- Focus feedback on the code and its impact.
- Explain technical disagreements with evidence.
- Protect private credentials and customer information.
- Make project discussions welcoming to people with different backgrounds and experience levels.

## Unacceptable Behavior

Harassment, discrimination, threats, personal attacks, disclosure of private information, and deliberately harmful project behavior are not acceptable.

## Reporting

Report concerns privately to the project maintainer through the repository's configured contact channel. Include enough context to investigate while avoiding unnecessary private or sensitive data.
